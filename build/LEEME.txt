VOODOO COMBO 0.1 — WINDOWS

Inicia el juego con VoodooCombo-0.1.exe.
No separes estos archivos:
- VoodooCombo-0.1.exe
- VoodooCombo-0.1.pck
- Godot_v4.7.2-stable_win64_console.exe

El ejecutable pequeño inicia el juego empaquetado con el runtime Godot 4.7.2.
Este paquete se generó porque las plantillas oficiales de exportación de Godot no estaban instaladas.
El runtime de consola incluido es el que utiliza el lanzador; no hace falta el ejecutable normal del editor.
